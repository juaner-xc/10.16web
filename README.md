# Quiz 后台管理作业

这是一个使用 **Vue 2 + Element UI** 完成的 Quiz 管理后台

## 已完成功能

- 用户管理：查询、添加、编辑、删除、分页
- 题目管理：查询、添加、编辑、删除、分页
- 题目弹窗包含问题内容、A/B/C/D 四个选项和正确答案
- 默认题库与现有 Quiz 前台 `https://quiz-game-phi-sooty.vercel.app/` 的 8 道题对应
- 数据自动保存在浏览器 `localStorage`，刷新后不会消失
- 自适应手机与电脑屏幕

## 本地运行

先安装 Node.js，然后在项目目录运行：

```bash
npm install
npm run serve
```

浏览器打开终端显示的网址即可。
